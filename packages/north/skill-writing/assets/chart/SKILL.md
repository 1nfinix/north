# 图表

## 先确认材料

- 数据来源：用户给的表格、文件或对话中的数字。缺少数据或口径不清时直接询问，不要编造或补齐数字。
- 图表要回答的问题（谁最大、怎么变化、占多少、分布如何）和使用场合（汇报 PPT、Excel 附件、网页、聊天里看一眼）。
- 读取文件前先看列名、单位和时间范围；发现缺失值、重复行或单位不一致时，先说明再处理。

## 选图

- **比较**类别大小：柱图；类别名称长或超过 8 个时用条形图，并按数值排序。
- **趋势**随时间变化：折线图；时间点少于 5 个时用柱图。
- **占比**：类别不超过 6 个时用饼图或环形图，否则用堆叠条形图或排序条形图。
- **分布**：直方图或箱线图。**两个指标的关系**：散点图。
- 一张图只回答一个问题；需要回答多个问题时拆成多张图。

## 做法

1. 取得 Python（有 `load_workspace_dependencies` 工具时用它，没有时用电脑上已有的 `python3` 或 `python`），用 pandas 整理数据；没有 pandas 时用 Python 自带的 `csv` 模块；把整理后的数据另存一份 CSV 放在工作区，便于核对。
2. 交互式 HTML：把本技能目录下的 `echarts.min.js` 复制到工作区（与 HTML 同一文件夹），HTML 用 `<script src="echarts.min.js"></script>` 引用；需要单个文件时把它的内容内联进 `<script>`。不要引用 CDN 或任何外网地址，内网电脑可能无法联网。
3. 图表要素：中文标题说明结论或问题，坐标轴写名称和单位，数值保留一致的小数位，图例只在多个系列时出现，提示框显示精确数值。
4. 颜色克制：单系列用一种颜色；需要强调时只把重点数据换成强调色，其余用灰色。不要依赖红绿区分含义。
5. 字体用系统字体栈：`"Microsoft YaHei", "PingFang SC", "Noto Sans CJK SC", sans-serif`。

## 交付

- 交互式图表：用 `present` 交付 HTML 文件（连同 `echarts.min.js`，或已内联的单个文件）。
- 需要图片时：加载 `browser-check`，打开该 HTML 并截图保存为 PNG，再用 `present` 交付。
- 目标是 Excel 或 PPT 时：加载 `office-xlsx` 或 `office-pptx`，用文件内的原生图表，便于同事继续编辑。
- 在回复中用一两句话说明图表的结论和数据口径。
