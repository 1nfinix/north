# 把单位 PPT 模板做成模板技能

每家单位的模板做成一个独立的技能文件夹，由管理员放进「设置 → 技能」打开的技能文件夹并分发给同事，放入后在设置页点「刷新」即可使用，不需要重启。一个单位有多套模板（日常汇报、专题会议、对外宣讲等）时，每套做一个模板技能。

## 文件夹结构

```
汇报模板/
├── SKILL.md
└── template.pptx        # 或 template.potx；文件名可自定，在 SKILL.md 中写明
```

## SKILL.md 写法

```markdown
---
name: 汇报模板
description: PPT 模板：本单位日常工作汇报模板（16:9），适用于部门例会、季度汇报和专题汇报。
user-invocable: true
---

# 汇报模板

- 模板文件：`template.pptx`
- 适用场合：部门例会、季度汇报、专题汇报。
- 版式用法：封面用「标题幻灯片」；章节过渡用「节标题」；正文用「标题和内容」；左右对比用「两栏内容」；结束页用「结束页」。
- 使用要求：不修改母版中的标志和页脚；图表配色按模板主题色；封面日期写到月。
```

要求：

- `description` 必须以「PPT 模板：」开头，汇报 PPT 技能靠这个前缀识别模板技能；后面写清适用场合，便于在多套模板中选择。
- `name` 可以用中文，由文字、数字和单个连字符组成，与文件夹同名；同事可以用 `/汇报模板` 指定使用它。
- 「版式用法」中的名称要与模板里的版式名称一致，可先用汇报 PPT 技能的 `inspect_template.py` 查看。
- 模板里的示例页会在生成时自动删除，不必手工清空；母版、版式、主题字体与配色保持模板原样。

## 制作模板时的建议

- 在 PowerPoint 的「视图 → 幻灯片母版」中，为封面、节标题、正文、两栏、仅标题、结束页各准备一个版式，并使用标准占位符（标题、正文、内容），不要用普通文本框代替占位符。
- 主题字体与主题配色在母版中设置好，生成的内容会自动沿用。
- 标志、页脚、页码放在母版或版式上，不放在示例页上。
