# 长文总结

## 先确认

- 读者和用途（快速了解、决策参考、汇报转述）、篇幅要求、关注重点（如风险条款、数据结论、行动要求）。
- 文件格式：Word、PDF、Excel、PPT 先读取全文再总结；文件过长时分章节读取，不要只读开头。

## 结构

1. **一句话结论**：文档最核心的结论或目的。
2. **要点摘要**：3–7 条，每条一句话，按重要性排序。
3. **分章节摘要**：沿用原文章节标题，每节 2–4 句。
4. **关键数据与日期**：表格列出数字、日期、金额及出处。
5. **风险与待确认事项**（如适用）：原文中模糊、矛盾或需要进一步核实的内容。

## 写法

- 只使用原文信息，不加入外部知识或推测；需要推断时明确写「推断：」。
- 每个要点注明出处（第 X 页 / 第 X 节 / 第 X 段），便于核对。
- 多份资料时，先分别总结，再写对比或综合结论，并注明各结论来自哪份资料。
- 保留原文的专有名词和数字写法。

## 交付

默认在对话中给出 Markdown。用户需要文件时，加载 `office-docx` 生成 `.docx`，再用 `present` 交付文件。
