# 文种选择与写法要点

## 常用文种

| 文种 | 适用范围 | 行文方向 |
|------|----------|----------|
| 决议 | 会议讨论通过的重大决策事项 | 下行 |
| 决定 | 重要事项决策部署、奖惩、变更或撤销下级决定 | 下行 |
| 公告 | 向国内外宣布重要事项或特定事项 | 下行 |
| 通告 | 在一定范围内公布应当遵守或周知的事项 | 下行 |
| 意见 | 对重要问题提出见解和处理办法 | 上行、下行、平行 |
| 通知 | 印发传达要求、批转转发公文、人事任免 | 下行 |
| 通报 | 表彰先进、批评错误、传达重要精神 | 下行 |
| 报告 | 汇报工作、反映情况、回复询问 | 上行 |
| 请示 | 请求指示、批准 | 上行 |
| 批复 | 答复下级请示事项 | 下行 |
| 函 | 不相隶属单位间商洽工作、询问和答复问题 | 平行、上行、下行 |
| 纪要 | 记载会议主要情况和议定事项 | 下行 |

## 写法要点

**通知**
- 一般一事一通知，内容具体明确，表述简练准确。
- 发布材料类通知：多用篇段合一或主辅段式结构；被印发的文本是主文，不作为附件。
- 部署工作类通知：开头说明发文缘由（不是开展事项本身的缘由）；主体层次分明、逻辑清晰；要求报送材料或反馈情况时，写明报送时限、联系人和联系方式。

**请示**
- 一文一事，只有一个主送单位，不得多头请示。
- 结尾写明请求事项，如「妥否，请批示。」

**报告**
- 不得夹带请示事项；原则上只有一个主送单位。

**批复**
- 准确引述来文单位、公文标题和文号，针对请示事项作出具体明确的答复。
- 一般不标注加急。

**函**
- 去函包括商洽函、询问函、请求函、推荐函等；复函回复不相隶属单位的来函。
- 一函一事，语气以商洽为宜，注意时效。

**通报**
- 写清事实、性质、处理结果和要求，表彰或批评都要有据可查。

**纪要**
- 写会议名称、时间、主持人、参会范围后，按议定事项逐条写明决定、责任单位和时限。
