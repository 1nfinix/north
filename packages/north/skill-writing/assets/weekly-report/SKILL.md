# 周报与工作汇报

## 先确认材料

- 汇报周期（起止日期）、汇报对象（直属领导、部门例会、跨部门）和篇幅要求。
- 原始材料：工作日志、任务清单、会议记录、数据表。缺少关键数字时直接询问，不要编造。

## 结构

1. **本期概要**：两三句话说明最重要的结果和整体进度。
2. **完成情况**：按项目或职责分组；每条写「做了什么 → 结果」，尽量给数字（完成率、数量、金额、时间）。
3. **进行中**：当前进度、预计完成时间。
4. **问题与风险**：影响、原因、已采取的措施、需要谁在什么时间前支持。
5. **下阶段计划**：具体事项、负责人、截止日期。

## 写法

- 结论先行，每条不超过两行；用动词开头（完成、推进、协调、修复）。
- 区分已完成和计划中，不把计划写成成果。
- 日期写绝对日期（如 2026年10月23日），不写「下周一」。
- 汇报对象是领导时突出结果和需决策事项；部门例会时突出协作和依赖。
