# 汇报 PPT

本技能目录下的 `scripts/` 提供三个脚本，用 `load_workspace_dependencies` 取得的 Python 运行（没有该工具时用电脑上已有的 `python3` 或 `python`），脚本与模板只读，输出放在工作区：

- `inspect_template.py <模板.pptx|.potx>`：列出模板的版式、每个占位符的类型和尺寸、主题字体与配色。
- `fill_template.py <模板> <内容计划.json> <输出.pptx>`：按内容计划用模板版式逐页生成，删除模板自带的示例页，检查文字是否超出占位符，并打印检查报告。
- `extract_deck.py <已有.pptx> <输出目录>`：把已有 PPT 每页的标题、要点、图表数据、表格、图片和备注提取为内容计划，并列出每个形状的编号。

内容计划的格式见 `references/content-plan.md`。

## 选模板

1. 用户在本次对话中给出了模板文件：用它。
2. 否则查看可用技能中描述以「PPT 模板：」开头的模板技能：只有一个就用它；有多个时按场合选择，拿不准就请用户选。加载该技能，按其说明找到模板文件（路径相对于那个技能的目录），并遵守其中的使用要求。
3. 都没有：用本技能目录下的 `assets/default-template.pptx`，并告诉用户可以让管理员按 `references/template-skill.md` 把单位模板做成模板技能。

## 选场景

**用模板新做一份**
1. 确认汇报对象、场合、时长和页数（没有要求时按每 1.5–2 分钟一页，并给提问留出时间）；缺少关键数字时直接询问，不要编造。按用法定文字量：现场讲解配合口述，字少、多用图表；会前预读或会后留存，页面本身要讲清完整内容；数据分析材料以图表和表格为主。
2. 运行 `inspect_template.py`，记下封面、目录、章节、正文、双栏、结束等版式。
3. 在对话中给出提纲：每页一行，写版式、标题（结论句）、2–4 个要点和呈现方式（文字、图表、表格）。用户确认或修改后再生成；用户要求直接出文件时，提纲照样作为依据并一并交付。
4. 按提纲写内容计划 JSON，运行 `fill_template.py`。

**已有 PPT 套用模板**（内容不变，只换版式）
1. 运行 `extract_deck.py` 得到内容计划，再运行 `inspect_template.py`。
2. 为每页选择最合适的模板版式，只改写计划中的 `layout`，不改内容；内容过多放不下时拆成两页并告诉用户。
3. 运行 `fill_template.py`。

**修改已有 PPT**（保留原格式）
1. 运行 `extract_deck.py` 查看每页内容和形状编号。
2. 加载 `office-pptx`，在原文件的副本上按编号修改文字、数据或增删页，不重建整页，不改未要求的内容。

**Word 或 Excel 做成 PPT**
1. 加载 `office-docx` 读取 Word 的标题层级和要点，或加载 `office-xlsx` 读取数据表；汇总数字以表中数据为准，不重新估算。
2. 整理成提纲，之后按「用模板新做一份」继续。

## 每页写法

- 一页一个观点；标题写成结论句，如「三季度存款增长 12%，超额完成目标」，不要只写「三季度存款情况」；标题末尾不加句号。
- 正文每页不超过 6 条要点，每条不超过约 25 个字；用短句，不放大段原文。
- 有数据就用图表：比较用柱图，趋势用折线图，占比用饼图（类别不超过 6 个）。图表标题写结论，标明单位、口径、数据来源和截止时间。
- 少做纯文字页：内容能表达成数字对比、前后对照、流程或时间线时，改用图表、表格或双栏版式；相邻几页换用不同版式，不要整套都是标题加要点。
- 结构：封面 → 目录（超过 8 页时）→ 总体结论 → 分章节（较长的汇报在章节之间用节标题页）→ 下一步计划或需要决策、支持的事项（写明责任人和时间）。较短的汇报可以省略目录和节标题页。
- 版式、字体和配色以模板为准，不自行添加艺术字、阴影、渐变和与内容无关的装饰图，也不在标题下加横线、在页面或卡片边上加装饰色条。正文左对齐，不居中。
- 字号不低于正文 14 磅、图注 10 磅：放不下时删减文字、换两栏版式或拆页，不继续缩小字号。

## 检查与交付

1. 读 `fill_template.py` 的检查报告：有超出的占位符时精简文字或拆页，再生成一次，直到报告没有超出项。
2. 加载 `office-render` 把每页渲染成图片，按顺序检查：文字超出或被截断；元素重叠，数据来源注释压到正文或图表；同类页面标题位置、字号不一致；浅底浅字等低对比；数字和单位被拆到两行；残留「××」「TODO」等占位内容和空白页。当前模型不能查看图片时，不要声称看过，依据检查报告并请用户打开文件确认。
3. 只修改有问题的页，重新生成后再检查一次这些页，然后交付，不反复循环。
4. 用 `present` 交付 `.pptx`，附上提纲和需要用户补充的信息。
